# Download Standby for Android

## [Download Android app](https://github.com/Payne47/standby-downloads/releases/latest/download/Standby.apk)

**No account or sign-in needed.** Open this page on your Android phone and tap the download link above.

### Install on your phone

1. Tap **Download Android app**.
2. Open the downloaded **Standby.apk** file.
3. If Android asks, allow your browser or Files app to install this app, then tap **Install**.
4. Open **Standby**. Connect to the crew Wi-Fi, then enter your name and the host's crew code.

If Standby is already installed, install this over it to keep your saved settings. Do not uninstall it first.
